# 钢铁防线 · 坦克大战

独立静态网页游戏，无第三方运行依赖，无需构建。访问 `/games/tanks/`，或直接打开 `index.html`。

- 5 张独立地图，自由选关和连续闯关，每关 8 / 10 / 12 / 14 / 16 台敌军。
- WASD / 方向键移动，空格 / J 射击，P 暂停；手机使用屏幕按钮。
- 砖墙可破坏；钢墙阻挡炮弹；水域阻挡坦克、允许炮弹通过；树林遮挡坦克。
- 初始 3 条生命，重生有 3 秒护盾；过关补充 1 条生命，上限 5 条。
- 基地被敌方炮弹击中或生命耗尽则失败。最高分保存在当前浏览器。
- 音效默认关闭，可手动开启；切换窗口自动暂停。

## 验证

运行 `node games/tanks/game.test.cjs`：9 组确定性回归测试，覆盖地图、碰撞、地形、击杀、重生、基地、五关状态流转与完整出兵，以及五关出生区之间的无破墙通路。

已在 Chrome 实际验证桌面 1440px 与手机 390px 布局，以及开始、移动、射击、暂停/继续、重开、五关选择、音效开关与触控事件；无页面脚本错误。

随个人网站仓库的 GitHub Pages 工作流发布，线上地址为 https://reb00t2018.github.io/games/tanks/ 。

## 地图美术

参照用户提供的街机地图重绘：石板地面、橙色细砖、动态青蓝水道、密集树林、钢墙和金色基地徽章。第一关采用双水道堡垒布局，其余四关调整桥口与障碍。纹理由 Canvas 本地绘制，无外部图片请求。

## 特殊敌军与道具

- 每 3 台敌军中有 1 台紫色星标特殊坦克，拥有 2 点装甲；击毁后等概率掉落四种道具之一。
- 道具保留 12 秒，仅我方碰到时自动生效，不需要按键。落点为附近陆地或草地，避开砖墙、钢墙、水域和基地。
- 强化弹药：新发射子弹伤害从 1 提升为 2，持续 8 秒。
- 渡河：我方可以进入水域，持续 10 秒；到期仍在水中则返回最近无敌军占据的陆地，并获得 1 秒重定位保护。
- 炸弹：立即清除当前场上所有敌军（包括装甲和紫色坦克），结算击杀与特殊掉落，播放爆炸；清除现有敌方炮弹。我方、基地及所有地形保持不变。尚未出场的敌军继续按批次出现。
- 基地护盾：10 秒内基地免疫敌方子弹，基地光圈和状态栏显示剩余时间。
- 同类限时道具重复拾取刷新持续时间，不叠加倍率；不同道具可同时生效。暂停冻结计时，切关或重开清空道具和强化。

新增验证：`node games/tanks/powerups.test.cjs`，10 组测试覆盖特殊出兵、随机掉落、安全落点、自动拾取、超时、四种效果、炸弹保留全部地形、暂停与关卡重置。连同原有 9 组测试共 19 组通过。浏览器额外验证了自动拾取、三种倒计时、基地护盾 UI、爆炸绘制和手机布局。
